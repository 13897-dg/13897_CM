# MIP-2 Image App

This is a sample Android Application developed for the MIP-2 assignment (Assisted code generation). 
The goal of this application is to retrieve and display random images from a public API, emphasizing a planning-first workflow guided by Markdown specification documentation.

## Application Purpose
The application fetches a list of images using a public API and displays them in a scrollable list. It demonstrates the use of a simple MVVM architecture and API integration using Kotlin and traditional XML Views in Android.

## API Used
- **Picsum Photos API:** `https://picsum.photos/v2/list`
