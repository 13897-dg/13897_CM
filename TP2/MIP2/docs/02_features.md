# Features

1. **Fetch images from API:** Call the Picsum API to retrieve a list of image metadata (ID, author, and download URL).
2. **Display images in a list:** Show the retrieved images in an aesthetic grid or vertical list structure.
3. **Refresh images:** Provide a pull-to-refresh or button-refresh mechanism so the user can fetch a new batch/page of images.
4. **Show loading indicator:** Display a visual loading indication (like a `ProgressBar` or `SwipeRefreshLayout` spinner) while the API call is in progress.
