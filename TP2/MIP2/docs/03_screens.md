# Screens

## Screen: Main Screen
**Components:**
- **Toolbar / Top App Bar:** Contains the app title.
- **SwipeRefreshLayout:** Wraps the list to provide pull-to-refresh functionality.
- **RecyclerView:** Displays the list or grid of images and their authors.
- **ProgressBar (Loading Indicator):** Shown centered when the app is fetching the initial dataset.
- **Error View (optional):** A text view or layout shown if the request fails, with a retry button.
